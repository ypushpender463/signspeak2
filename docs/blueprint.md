# **App Name**: SignSpeak

## Core Features:

- Video/Audio Capture: Live video feed for capturing user input (English audio or ASL video).
- English-to-Text Conversion: Real-time English speech-to-text transcription using Whisper.
- Text-to-ASL Animation: Generative AI tool for translating text to ASL gloss, pose, and animation data.
- ASL Animation Display: Rendered ASL animation display, using Canvas/Three.js/Lottie or other suitable method.
- ASL Pose Extraction: Pose extraction from webcam video frames.
- ASL-to-Text Translation: Generative AI tool for converting pose data to ASL gloss and English text.
- Text Display & TTS: Translated English text display and text-to-speech playback.

## Style Guidelines:

- Primary color: A calm blue (#4A8FE7) evoking communication and understanding.
- Background color: A very light, desaturated blue (#F0F5FA) providing a clean backdrop.
- Accent color: A slightly brighter and more saturated green-blue (#43C6AC) to highlight key interactive elements.
- Body and headline font: 'Inter' sans-serif font for clear and accessible readability. 
- Simple, intuitive icons to represent different functions and settings.
- Clear, modular layout with distinct sections for video feeds, text displays, and controls.
- Smooth, subtle transitions and animations to enhance user experience.
